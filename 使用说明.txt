1Panel 面板一键安装器 · 桌面版
============================================================

一、这是什么

一个 Windows 桌面程序。填写服务器 IP、SSH 端口、root 密码后，程序会自动：
  1. 通过 SSH 连上你的服务器
  2. 识别系统类型、版本与 CPU 架构（Ubuntu / Debian / CentOS / RHEL / Alma / Rocky / 麒麟 / UOS 等）
  3. 按架构匹配 1Panel 官方 v2 安装包，并可选择中文版（国内源）或英文版（国际源）
  4. 调用 1Panel 官方 install.sh 非交互安装，支持同时安装 Docker
  5. 安装完成后把面板地址、用户名、密码、端口、安全入口直接显示给你

全程不需要打开浏览器，也不需要懂命令行。


二、怎么用

1. 双击  1Panel-Installer.exe
2. 首页四个入口，按需选择：

   · 开始安装     —— 四步向导：服务器信息 → 安装配置 → 自动安装 → 安装完成
   · 面板急救箱   —— 忘记面板地址/账号/端口，或面板打不开时直接处理
   · 域名与HTTPS  —— 检查域名解析、读取面板访问协议与 HTTPS 状态
   · 直接给我命令 —— 生成一条可复制的官方安装命令，自己拿到 SSH 里执行

3. 右上角「VPS聚合站」可跳转 www.vpsjh.com；另有 1Panel 官网与 GitHub 入口。
4. 关掉窗口即退出，后台本地服务随之结束。


三、系统要求

· Windows 10 / Windows 11，64 位
· 需已安装 Microsoft Edge WebView2 Runtime（Win11 自带；缺失时程序会提示下载地址）
· 目标服务器：Ubuntu 18.04+ / Debian 10+ / CentOS 7+ / RHEL 8+ / AlmaLinux 8+ /
  Rocky Linux 8+ / Fedora / openEuler / Anolis / OpenCloudOS / 麒麟 / UOS 等
· 目标服务器 CPU 架构：amd64 / arm64 / armv7 / ppc64le / s390x / riscv64
· 必须以 root 身份执行安装（1Panel 官方脚本强制要求）
· 不需要管理员权限，不需要装 Node.js

五、安装流程说明

· 测试连接：先确认 SSH 能登上，程序会顺带识别系统、版本、架构、内存、磁盘和 Docker 状态
· 系统不在官方支持列表时会提示；确认兼容后可勾选「我已确认兼容」继续尝试
· 不支持的系统版本（如 CentOS 6、Debian 9）和不在支持范围的 CPU 架构会被直接拦下
· 安装语言：中文版使用 resource.fit2cloud.com 国内源，默认中文界面；
  英文版使用 resource.1panel.pro 国际源，默认英文界面；安装后都可在面板设置里切换语言
· 面板用户名、密码、端口、安全入口、安装目录都可自定义，留空自动生成
  - 用户名/安全入口：3–30 位字母、数字、下划线
  - 密码：8–30 位，允许字母、数字和 _ ! @ # $ % * , . ?
  - 端口：1–65535，默认随机 20000–40000
· Docker 默认勾选安装（1Panel 应用商店依赖 Docker）；可选内置包优先或在线安装
· 中文版默认写入 1Panel 的 Docker 镜像加速地址，海外服务器可关闭
· 安装包约 80 MB，耗时一般 3–8 分钟，取决于服务器网络与磁盘
· 安装完成后会显示面板地址、用户名、密码；地址末尾的安全入口路径必须带上


六、安全说明

· 后台服务只监听 127.0.0.1:3942，局域网内其它设备无法访问
· SSH 密码只存在于内存，不写盘、不上传，不经过第三方
· 安装命令中的面板密码通过 PANEL_PASSWORD 环境变量传入，不出现在进程参数里；
  界面日志显示的密码已替换为 **********
· 安装完成后建议在云控制台放行面板端口（TCP），并在面板内修改初始密码
· 1Panel 默认 HTTP 访问，登录安全依赖安全入口与强密码；可在面板「设置 → 面板 → HTTPS」启用证书


七、常见问题

Q：提示「系统不受支持」？
A：1Panel 官方推荐 Ubuntu / Debian / RHEL 系 / 国产系统。版本过低或不支持的架构无法安装，
   请更换系统；未识别的系统可在勾选确认后尝试。

Q：安装很慢或卡在下载？
A：中文源慢可点「换安装源重试」切换到英文（国际）源；反之亦然。也可检查服务器到官方源的网络。

Q：面板地址打不开？
A：① 云安全组放行面板端口（TCP）；② 地址要带安全入口路径；
   ③ 急救箱「查看面板信息」，或在服务器执行 1pctl user-info 核对。

Q：忘了面板密码或安全入口？
A：用「面板急救箱 → 重置面板密码 / 重置安全入口」，底层调用 1pctl update password / reset entrance。

Q：服务器已装过 1Panel？
A：官方安装脚本会拒绝重复安装。请直接使用现有面板，或先在服务器执行 1pctl uninstall 卸载。

Q：杀毒软件报毒？
A：1Panel-Installer.exe 是 16KB 的 .NET 小程序，常见误报，加入信任即可。
